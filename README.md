Плагин ВКонтакте для OpenClaw. Получает сообщения через VK Bot API и передаёт их в OpenClaw.

## Настройка

### 1. На стороне ВК

1. Создайте сообщество ВК
2. **Управление Сообществом > Дополнительно > Работа с API > Создать ключ** - с разрешением к управлению сообществом, сообщениям, фотографиям, документам
3. Запишите числовой **ID группы**
4. Включите Long Poll API и разрешите ему все действия из сообщений, фото, аудио

### 2. Установка

```bash
# npm (когда будет опубликован)
openclaw install @openclaw/vk

# или симлинк локально
ln -s /path/to/clawd-vk extensions/vk          # Linux/macOS
New-Item -ItemType SymbolicLink -Path extensions\vk -Target C:\path\to\clawd-vk  # Windows (админ)
```

### 3. Настройка в OpenClaw

1. Откройте панель OpenClaw, в боковом меню перейдите в **Control > Channels**
2. Найдите секцию **VK** и раскройте её
3. Заполните поля:
   - **Allow From** - список VK-профилей, от которых бот будет принимать сообщения (формат: `https://vk.com/username`). Нажмите **+ Add**, чтобы добавить пользователя
   - **Group ID** - числовой ID вашего сообщества ВК
   - **Community Bot Token** - токен API сообщества (из шага 1)
4. Нажмите **Save**

После сохранения канал появится в статусной карточке выше - убедитесь, что **Running: Yes** и **Configured: Yes**.
